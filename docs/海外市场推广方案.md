# 家宴海外市场推广方案

> 文档状态：推广方案草案
>
> 更新日期：2026-11-10

## 一、推广目标与前提

家宴帮助家庭保存常做的菜、一起决定吃什么，并整理购物清单和用餐记录。海外推广初期的目标是找到真正需要这套流程的人，验证他们是否愿意反复使用和邀请家人，再决定是否扩大投入。

本文以**美国或加拿大的海外华人家庭**作为首轮试点假设，逐步接触英语用户；具体国家、预算和上线时间尚未确定。先选一个市场、一个主要人群和一到两个渠道，不把英语用户视为同一种人群。

产品改造范围另见 [海外推广优化改造说明](./海外推广优化改造说明.md)。付费投放前至少要保证：目标语言核心流程可用、登录及邀请可用、隐私说明清楚、海外访问和邮件经过实测、用户有反馈渠道。尚未实现的能力不能用于宣传。

## 二、目标人群与定位

| 人群 | 可能的需求假设 | 建议沟通方式 |
| --- | --- | --- |
| 海外华人家庭 | 想保存家常菜、和家人商量吃什么，也可能有中英文混合沟通需求。 | 先用中文展示真实家庭场景；支持后再展示双语邀请。 |
| 经常做饭的英语用户 | 想减少每天决定吃什么的沟通成本。 | 用清晰演示说明保存菜品、家庭选择和采购清单。 |
| 聚餐组织者 | 想在聚餐前收集家人朋友想吃的菜。 | 重点演示链接邀请和共同点菜，说明参与方式与有效期。 |

这些是待访谈验证的假设，不是已验证的用户需求或市场规模。

**核心定位候选**：把家里的拿手菜保存下来，一家人一起决定下一餐。

**英文文案候选**：Keep your family favorites in one place. Decide what to eat together.

辅助表达可以围绕「不再反复问吃什么」「让家人一起选」「把决定好的菜整理成购物清单」展开。营养分析和 AI 清单应说明是估算或建议，不能宣传为医疗建议、过敏安全保证或自动精确食谱。

## 三、推广渠道

| 渠道 | 用法 | 启动顺序 | 判断方式 |
| --- | --- | --- | --- |
| 熟人及海外华人社群 | 邀请有做饭习惯的家庭试用，通过相关群组、社区组织招募访谈；先了解规则并取得发布许可。 | 首批 | 有效访谈、完成首次建菜单和再次使用的家庭数。 |
| 短视频与图文 | 在目标用户常用的 Instagram、TikTok、YouTube Shorts 等渠道测试真实使用演示，先选择有能力持续维护的平台。 | 首批 | 视频有效访问、落地页访问及后续激活；不能只看播放量。 |
| 相关社区 | 参与海外华人、家庭做饭和 meal planning 话题，先提供有用内容；遵守各社区的推广规则。 | 首批 | 合规发布后的访问与有效反馈。 |
| 小型内容创作者 | 选择与家庭做饭、跨文化家庭或生活组织相关的创作者，先邀请真实试用，再商量合作；不要求虚假好评。 | 产品流程稳定后 | 每位创作者带来的激活家庭和反馈，结合制作及合作成本评估。 |
| 搜索与内容 | 建立英文落地页和帮助内容，测试用户实际搜索方式，例如 family meal ideas、decide what to cook；关键词是否有效需验证。 | 持续积累 | 搜索进入、关键页面转化和后续激活。 |
| 应用商店 | 如后续实际上架，再优化商店文案、截图和当地语言素材，测试不同卖点。 | 上架后 | 商店展示、访问、安装及激活；小样本不急于下结论。 |
| 付费广告 | 用少量预算测试已有正向反馈的素材和人群。 | 自然渠道验证后 | 激活成本、回访及分享，不只比较点击成本。 |

创作者合作须根据目标市场要求明确披露付费或其他利益关系，例如面向美国用户时参考 [FTC 指南](https://www.ftc.gov/business-guidance/resources/disclosures-101-social-media-influencers)。若未来上架，Apple 和 Google Play 均提供商店页面素材测试能力，详见 [Apple 产品页面](https://developer.apple.com/app-store/product-page/) 和 [Google Play 页面实验](https://support.google.com/googleplay/android-developer/answer/12053285?hl=en)。

## 四、推广素材与转化路径

### 4.1 基础物料

1. **中英文介绍页**：一句话解释用途，展示真实界面、三步使用流程、常见问题、隐私说明和反馈入口；根据实际发布状态提供访问或安装指引。
2. **短演示视频**：每条聚焦一个真实场景，如“保存几道家常菜”“邀请家人点菜”“根据菜单整理买菜清单”；字幕使用目标受众语言。
3. **真实使用截图**：手机同一状态下截取界面，展示中英文版本实际效果；不展示真实用户隐私或未经授权的照片。
4. **试用邀请文案**：说明产品能做什么、适合谁、如何反馈，以及功能是否仍在测试。
5. **帮助与客服**：准备注册、邀请过期、安装 PWA、照片和账号问题的简短说明，以及可联系到人的渠道。

### 4.2 建议体验路径

内容或社群介绍 → 产品介绍页 → 注册 / 登录 → 添加或选择第一道菜 → 创建菜单 → 邀请家人 → 家人完成选择 → 回访使用。

受邀者的访问应单独观察：其可能不需要注册，不能把未注册的参与者都当作流失。每一步都应先确认现有产品是否已支持；示例菜单、免登录体验或安装引导如未上线，不应提前承诺。

## 五、分阶段执行

### 第 1–2 周：验证需求与准备

- 明确一个首发国家、语言和渠道；招募约 10–15 位符合画像的潜在用户访谈，数量仅为试点目标。
- 观察用户当前如何决定吃什么、管理家庭菜品和采购，而不只询问是否喜欢产品。
- 完成产品演示、介绍页、隐私说明和反馈渠道；按改造文档检查核心流程。
- 输出：访谈记录、前三个主要需求、待修问题和第一批推广素材。

### 第 3–4 周：小范围试用

- 邀请首批家庭完成至少一次真实用餐流程；记录卡点和用户原话，经同意后收集反馈。
- 测试两种表达，例如“家庭一起点菜”和“保存家常菜”，每种对应清晰的渠道来源。
- 每周整理新增问题和改进，优先修复注册、邀请、同步等阻断问题。
- 输出：参与家庭数、关键流程完成情况、回访情况和产品改进清单。

### 第 5–8 周：扩大有效渠道

- 对已经有积极反馈的渠道保持稳定更新；可邀请少量相关创作者真实体验。
- 核心流程稳定、数据口径明确后，再使用小额广告测试素材与受众。
- 每周复盘从访问到激活、回访和邀请的转化；对小样本使用人数和用户反馈，不将波动当成确定趋势。
- 输出：渠道对比、单个有效家庭获取成本、用户反馈和是否扩大推广的决策。

时间与人数均为建议性试点安排，实际应由产品准备程度、团队人力和市场选择调整。

## 六、预算示例

以**8 周总预算上限 1,000 美元**为示例，不代表报价或收益预测；实际费用、税费和创作者合作价格需另行确认。

| 用途 | 上限示例 | 说明 |
| --- | ---: | --- |
| 访谈与试用感谢 | $250 | 用于合理的参与补偿；不以好评为条件。 |
| 素材制作与翻译校对 | $250 | 包含英文母语校对或必要的外部制作。 |
| 小型创作者合作 | $200 | 仅在找到合适合作对象时使用，明确披露关系。 |
| 小额广告测试 | $200 | 自然试用和核心流程通过后再投入。 |
| 预留 | $100 | 用于调整或补充测试。 |
| **合计上限** | **$1,000** | 不含内部人力及产品开发成本。 |

如果预算为零，可以先使用自制素材、熟人试用和经许可的社群招募，不把创作者合作或付费投放设为前提。

## 七、数据口径与复盘

先确认数据收集的适用依据和用户告知，避免采集菜名、照片、日记内容或邀请令牌等非必要信息；当前项目是否已有完整统计能力需另行确认。试点初期可在用户同意的情况下结合匿名汇总与人工记录。

| 指标 | 建议定义 |
| --- | --- |
| 访问人数 | 在统计周期内访问介绍页的去重人数；注明去重方法与局限。 |
| 注册完成率 | 完成注册人数 ÷ 开始注册人数；单独记录邮件验证失败。 |
| 激活家庭 | 注册后 7 天内创建菜单并选择至少一道菜的家庭；正式实施前统一“家庭”去重口径。 |
| 邀请参与率 | 发出邀请的菜单中，至少一位受邀者实际完成选择的比例。 |
| 第 7 天回访 | 在首次使用后的第 7 天回访的家庭 ÷ 可观察满 7 天的首次使用家庭；可另看第 8–30 天回访。 |
| 有效家庭获取成本 | 某渠道总推广支出 ÷ 该渠道归因的激活家庭数，注明归因方法及无法识别的部分。 |
| 定性反馈 | 记录用户实际使用场景、完成或放弃的原因，以及重复出现的问题。 |

这些指标是拟议口径，不代表当前已有埋点。跨设备、隐私限制和小样本会影响归因与回访统计，应保留未知来源，不把估算当作精确值。

**复盘决策**：如果用户看不懂价值，调整定位和演示；如果注册、邀请或访问失败，优先修复产品；如果能完成首次使用但很少回访，访谈使用场景后再增加推广投入。只有在核心流程稳定、真实用户愿意回访且单位成本可接受后，才考虑扩大预算。

## 八、待确认事项

1. 首发国家或地区、首发语言和优先人群是什么？
2. 产品首发渠道是现有 PWA、Android 外壳，还是未来上架应用商店？
3. 可投入的预算、执行周期和负责内容、客服与数据分析的人力是多少？
4. 目前有哪些海外用户、社群或创作者资源，以及是否允许在这些渠道发布？
5. 推广前英文版、隐私说明、账号恢复、海外网络和数据统计分别何时可用？
